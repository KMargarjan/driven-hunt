2. `src/server/ForestTest/init.luau` / `promote` + `src/server/ForestTestBoot.server.luau` boot order — the boar field is never swapped for the FIRST drive of a session, and the first dealt layout is never the road, so the first drive of every session runs a non-road layout against the road's field.
