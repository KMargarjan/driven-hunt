1. `src/server/Bots/init.luau` / `stepWalker` — the forced side-step never fires in the only world that has obstacles, so a stuck bot never recovers. Evidence: `local room = world ~= nil and world.roomToStand ~= nil` / `if room or forced > 0 then` / `local clear = if room then world.roomToStand(aim, config.LANE_CLEAR_STUDS) else false` / `if not clear then`.
