# driven-hunt

Roblox game, developed with Rojo. See `CLAUDE.md` for rules, layout and the full run/test guide.

## First-time setup (Windows)

1. Install [Rokit](https://github.com/rojo-rbx/rokit), then in this folder run: `rokit install`
2. `wally install` (restores `DevPackages/`, which holds TestEZ)
3. `rojo serve`
4. In Studio, open **Driven Hunt DEV**, then **Plugins → Rojo → Connect**.
5. Press **Play**. The Output shows `sync ok` and `[tests] PASS: 2 passed, 0 failed, 0 skipped`.
